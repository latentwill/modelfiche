The first Windows release of Modelfiche: a local workbench for datasets, captions, image-model training runs, checkpoints, and visual comparisons.

### Download and open

Download **Modelfiche-0.1.0-windows-x64.zip**, choose **Extract All**, then open **Modelfiche.exe**. Keep the launcher open while you use the app in your browser. Close the launcher to stop it.

- Windows 10/11, 64-bit Intel/AMD, with .NET Framework 4.8.
- Bundled Python, API, worker, web UI, W&B-compatible ingress, migrations, and `mfiche.exe` CLI.
- No Python or Node installation and no administrator rights required.
- Workspace data stays in `%LOCALAPPDATA%\Modelfiche`, separate from the app folder.
- The executable is unsigned; Windows may show an unknown-publisher or SmartScreen notice. A SHA-256 manifest is included.

Built on Windows Server 2022 using GitHub Actions. Automated validation covers launching the extracted native app, database setup, local image import and delivery, credential storage, CLI commands, duplicate launches, backups, restart persistence, and service cleanup. Interactive testing on a physical Windows 10/11 PC has not been performed.
